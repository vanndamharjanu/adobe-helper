1. JPG vs Vector (.SVG / .EPS)

Gunakan Upscale JPG (minimal 4MP) untuk foto atau 3D render. Gunakan Vector (.SVG / .EPS) hanya untuk ilustrasi flat, logo, dan ikon agar tidak ditolak kurator.

2. Aturan Metadata Adobe Stock

Sepuluh keyword pertama memiliki prioritas tertinggi. Hindari mencantumkan merek dagang, nama kamera, atau istilah seperti 4K, Midjourney, Photorealistic. Saat upload di Adobe Stock, centang opsi Created using generative AI tools.
